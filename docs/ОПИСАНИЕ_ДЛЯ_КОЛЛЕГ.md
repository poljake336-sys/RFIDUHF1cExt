# Внешняя компонента RFIDUHF для мобильной 1С — краткое описание

**Автор:** Каюмов А.Р.  
**Дата:** 02.10.2026  
**Репозиторий:** https://github.com/poljake336-sys/RFIDUHF1cExt (private)  
**Готовый файл для 1С:** `dist/RFIDUHF.zip`

---

## Задача

Своя **Native AddIn**-компонента для мобильной платформы 1С на Android, чтобы на ТСД **Chainway C72** читать UHF RFID-метки **напрямую из 1С**, без Data Mobile и сторонних приложений-посредников.

---

## На чём основано

| Источник | Что взяли |
|----------|-----------|
| [ripreal/androidUtils1cExt](https://github.com/ripreal/androidUtils1cExt) (Infostart / Igor Kisil) | **Шаблон** каркаса внешней компоненты 1С для Android: C++ Native API ↔ JNI ↔ Java, упаковка в zip-макет |
| Chainway **DeviceAPI** (AAR `DeviceAPI_ver20251103_release`) | Официальный SDK RFID для C72: класс `RFIDWithUHFUART` |
| Официальное демо Chainway UHF | Логика inventory / мощность / одна метка |

Собственная реализация: API под задачу склада/полки, события в 1С, тестовый zip, тестовая тестовая мобильная конфигурация.

## Что реализовано

### Компонента `AddIn.RFID.RFIDUHF`

**Методы:**  
Инициализировать, Завершить, НачатьИнвентаризацию, ОстановитьИнвентаризацию, СчитатьОднуМетку, УстановитьМощность (5–30 dBm), УстановитьЧастотныйРежим

**Свойства:**  
ОписаниеУстройства, Подключено, ИнвентаризацияАктивна, Мощность, ПоследняяОшибка

**События в 1С (`ВнешнееСобытие`):**  
- источник: `org.rfiduhf.addin`  
- `TagRead` — JSON с EPC / TID / RSSI / временем  
- `Error` — текст ошибки

### Поставка

- Готовый **`RFIDUHF.zip`** — кладётся в общий макет конфигурации как двоичные данные  
- Пример BSL для мобильного клиента  
- Тестовая мобильная конфигурация `mobile-cf/` с формой «Полная проверка API»

### Как проверять

1. Собрать МП из конфигурации с макетом `RFIDUHF`  
2. Установить на **Chainway C72**  
3. На форме: подключение → «Полная проверка API» → Старт с меткой  

На обычном планшете/эмуляторе без UHF проверяется только загрузка AddIn; чтение меток — только на C72 (или совместимом ТСД с тем же DeviceAPI).

## Важно для внедрения

- В УТ 11 / толстом клиенте Windows компонента **не запускается** — только мобильная платформа Android.  
- На клиенте МП подключение только **асинхронное** (`НачатьПодключениеВнешнейКомпоненты`).  
- При закрытии формы обязательно: остановить инвентаризацию + `Завершить()` (иначе модуль UHF на C72 может «зависнуть»).  
- Для узкой зоны (полка) мощность начинать с **10–15 dBm**, не с максимума.
