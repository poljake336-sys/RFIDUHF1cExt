# RFIDMobileTest — мобильная конфигурация для теста RFIDUHF

Назначение: проверка Native AddIn `RFIDUHF` на ТСД Chainway C72 (мобильная платформа 1С).

**Не путать с УТ 11.5.** Папка `E:\13.08.26 - Конфигурация ут11.5 для разработки ТСД` — это десктоп/расширение. Android-компонента в толстом клиенте УТ не работает.

## Что внутри

| Объект | Назначение |
|--------|------------|
| `ОбщийМакет.RFIDUHF` | `RFIDUHF.zip` (arm64-v8a Native AddIn) |
| `Обработка.ТестRFID` | Форма: Старт / Стоп / мощность / список EPC |
| `Роль.ПолныеПрава` | DefaultRoles |
| UsePurposes | **MobileDevice** |

Источник zip: `E:\RFIDUHF1cExt\dist\RFIDUHF.zip`

## Как загрузить в 1С

1. Создать **пустую ИБ мобильной платформы** (или загрузить XML в конфигуратор МП).
2. Конфигуратор → Конфигурация → Загрузить конфигурацию из файлов → указать каталог `E:\RFIDMobileTest`.
3. Обновить конфигурацию БД.
4. Собрать мобильное приложение / выгрузить на ТСД (сборка МП 1С под Android).

Альтернатива: создать `.cf` из этой выгрузки и загрузить как конфигурацию.

## Что реально тестируется

| Среда | Что проверите |
|-------|----------------|
| Эмулятор / телефон без C72 UHF | Открытие МП, форма, **ошибка init/подключения** компоненты (ожидаемо) |
| Chainway C72 + сборка МП | Init, мощность, inventory, ExternalEvent TagRead, список EPC |
| УТ 11.5 (десктоп) | **Нельзя** — только обмен с МП позже |

## Подключение компоненты

На МП синхронный `ПодключитьВнешнююКомпоненту` запрещён («Использование синхронных методов на клиенте запрещено»).
Форма использует `НачатьПодключениеВнешнейКомпоненты` + `ПослеПодключенияКомпоненты`.

## Кнопки формы

- **Старт** — `НачатьИнвентаризацию`
- **Стоп** — `ОстановитьИнвентаризацию`
- **Мощность** — 5..30 dBm (для полки начните с 10–15)
- **Очистить** — очистка таблицы меток

При закрытии формы вызывается `Завершить()` (иначе UHF на C72 может «зависнуть»).
